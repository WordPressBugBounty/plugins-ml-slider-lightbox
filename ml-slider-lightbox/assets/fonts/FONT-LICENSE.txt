Bundled fonts
=============

These web fonts are bundled and self-hosted (no remote requests) and are used
only on the Galleries admin screen. Both are licensed under the SIL Open Font
License, Version 1.1.

Full license text: https://openfontlicense.org/open-font-license-official-text/


Montserrat  (montserrat-latin.woff2)
------------------------------------
- Heading typeface.
- Copyright The Montserrat Project Authors
  https://github.com/JulietaUla/Montserrat
- Licensed under SIL OFL 1.1. Reserved Font Name: "Montserrat".
- Latin subset, weight 700 (variable file).


Source Sans 3  (source-sans-3-latin.woff2)
------------------------------------------
- Body typeface (the current, actively-maintained version of "Source Sans Pro").
- Copyright 2010-2020 Adobe (https://adobe.com/), with Reserved Font Name "Source".
- Licensed under SIL OFL 1.1.
- Latin subset, variable weight 400-700.


Files were obtained from Google Fonts (fonts.gstatic.com) as latin-subset woff2.
